## 1. מילון מונחים (HE ↔ EN)

| מונח | English | הערה |
|---|---|---|
| מועדון / טננט | Tenant | הישות העליונה של הבידוד; מאמן עצמאי = טננט עם סניף אחד מרומז |
| סניף | Branch | תת-יחידה ארגונית (D18) |
| עונה | Season | טווח התאריכים שמאגד את כל הפעילות (2026/27) |
| קבוצה | Group | קבוצת אימון עם סדרות מפגשים |
| **סדרה** | SessionSeries | לו"ז חוזר ("כל שני 18:00"); מייצרת מופעים |
| **מופע** | SessionOccurrence | מפגש ספציפי בתאריך — בעל מזהה יציב; אליו נקשרות נוכחות והערות |
| הוראת-על / חריגה | Override | ביטול/שינוי של מופע בודד מתוך סדרה |
| אימון (תוכן) | Training | יחידת תוכן בספרייה — סטים, מרחקים, אזורים |
| סט | EnduranceSet / WorkoutStep | שורה באימון (כולל כפולות, מנוחות, סגנונות) |
| **תוכנית** | Program | מקרו-מחזור רב-שבועי (לקבוצה או ליחיד) |
| פאזה / בלוק | MesoBlock | שלב בתוכנית (Base/Build/Peak/Taper/חופשי) |
| שבוע מתוכנן | PlannedWeek | יעדי נפח ופילוח אזורים לשבוע |
| אימון מתוזמן | ScheduledWorkout | מקום אימון ביום-ושבוע של התוכנית |
| שיוך | TrainingAssignment | הפעלת תוכנית → אימון שהוקצה לספורטאי/קבוצה |
| **ביצוע בפועל** | PerformanceLog | רשומת ביצוע מכל מקור (מאמן/ספורטאי/הורה/שעון) |
| נוכחות | Attendance | סטטוס נוכחות למופע (ATTENDED/LATE/MISSED/EXCUSED) |
| **מבחן** | Test | מדידה (5K, FTP, CSS...); מייצר גרסת אזורים |
| **אזורים** | Zones (ZoneVersion) | טווחי עבודה לפי מדד — עם היסטוריית גרסאות |
| **קטלוג** | SportCatalog | ענפים/מבחנים/שיטות אזורים — מוגדר פר-טננט (D9) |
| יכולת | Ability | רמת מתאמן — מנתבת מסלולים/קבוצות/התאמות (D8) |
| **דגל** | Flag | אות במרכז הבקרה ("דורש תשומת לב") |
| ציות | Compliance | % ביצוע/נוכחות בפועל מתוך הוקצה |
| **מתקן** | Facility | בריכה/אולם/מסלול; מסלולי בריכה = Lanes |
| **אפוטרופסות** | Guardianship | הורה מנהל חשבון ספורטאי קטין עד מעבר שליטה |
| חשבונית/אסמכתא | Invoice/Receipt | מסמכי תשלום בסטנדרט ישראלי (Morning-like) |
| **חלון הזמנה** | OrderWindow | טופס הזמנה מוגבל בזמן (ביגוד/ציוד) |
| מגזין | ContentPost | תוכן מקצועי בהיקף חשיפה מוגדר |
| **חסם מתחרים** | Moat | יתרון שהופך עזיבה/התחרות ליקרה. אצלנו: נבנה מהנתונים שמצטברים (היסטוריה, בנק אימונים מתויג) + החיבורים בין-מודוליים — לא מחסימת יציאה (יצוא זמין תמיד — ARC-10) |

## 3. צ'קליסט משפטי/רגולטורי (לאישור עו"ד לפני עלייה לפרוד)

- [ ] תנאי שימוש + מדיניות פרטיות (מאמנים, ספורטאים, הורים) — כולל פרטיות קטינים.
- [ ] הסכמות חתומות: מדיקלי (הרשאת חירום), ביטוח, **מדיה (פרסום תמונות/וידאו)**, ותנאי השימוש ברישום.
- [ ] הגדרת אחריות מול נתוני בריאות (המערכת מציגה ואינה מייעצת רפואית — disclaimer).
- [ ] מדיניות מחיקת נתונים ואחזקה (ARC-10) בהתאם לחוק הגנת הפרטיות.
- [ ] פרסומות לקהל שכולל קטינים — בדיקת התאמת רשת הפרסום והמיקומים.
- [ ] מסמכי כספים: מעמד המאמנת (עוסק מורשה/עמותה) קובע את סוג המסמכים (חשבונית/אסמכתא).

## 4. נוהל AC — קריטריוני קבלה לכל פיצ'ר (DoD §3 מורחב)

לפני מימוש כל פיצ'ר נכתב לו כרטיס עם:
1. **הקשר**: איזו דרישה (REQ-xx) הוא מממש ואילו באגי AS-IS הוא סוגר.
2. **תרחישים** בשפת משתמש: "בתור מאמנת, כשאני פותחת את מפגש שלישי, אני רואה...". כל תרחיש = AC אחד בר-בדיקה.
3. **מקרי קצה**: רשימת ידועים (ראשון בחודש, 29 בפברואר, ספורטאי בלי מבחן, מופע שבוטל, 300 ספורטאים ברשימה).
4. **הרשאות**: מה כל תפקיד רואה/מורשה בפיצ'ר זה (מטריצת בדיקה קטנה).
5. **RTL/i18n**: המסך עובד בעברית ובאנגלית.
6. **מדד**: איך נודע בפרוד שהפיצ'ר עובד (למשל: % מופעים עם נוכחות מתועדת עולה).

כרטיס שלא עומד בכל AC — הפיצ'ר לא נחשב גמור, גם אם "עובד".
