# כרטיס פיצ'ר — F0.1: Postgres + הגירה

> REQ: ARC-2, D15, D23, D29 · סוגר AS-IS: §5 (fileDb), 1.2 (חלקית — טיפוסים), 4.17 (POST משמיט שדות — לא ב-F0.1), ניקוי נתונים מתועד
> AC (roadmap): כל הנתונים הקיימים נגישים דרך ה-API · גיבוי רץ

## תרחישים (בשפת משתמש)

1. כמאמנת, אחרי ההגירה אני פותחת את האפליקציה ורואה **בדיוק את אותם נתונים** — קבוצות, ספורטאים, מבחנים, תוכניות, נוכחות, הערות — רק שהם כעת ב-Postgres.
2. כמפתחת, אני מריצה `npm run migrate` פעם אחת — וה-DB החדש מקבל את כל database.json, עם דוח ניקוי (מה תוקן).
3. כל route קיים ממשיך לעבוד ללא שינוי התנהגות (אותן תשובות, אותם קודי סטטוס).
4. אני מריצה `npm run backup` ומקבלת קובץ גיבוי מתויג בזמן בתיקייה מקומית (gitignored — פרטיות).
5. מעבר ל-Supabase = החלפת `DATABASE_URL` ב-`.env` + הרצת migrate — בלי שכתוב קוד.

## מקרי קצה (מנוקים בהגירה)

- מספרים שנשמרו כמחרוזות (`age: "6"`, `weight: "60"`) → int או null. ריק/NaN → null.
- `group.athletes` מערבב מזהים ושמות → שמות מתורגמים למזהים לפי התאמת שם ל-athletes; בלתי-מתורגמים נשמטים **עם דוח** (האמת חיה ב-athlete_groups).
- `athlete.groups` — אותו ניקוי.
- `schedule[].day` נשמר כמחרוזת → int (1.3 ב-AS-IS).
- `attendances.event_id` מפנה למופעים מסונתזים → **בלי FK** (מופעים יציבים הם F1.2).
- `training_assignments.training_id` יכול להצביע על אימון שנמחק (snapshot) → בלי FK.
- מזהים ישנים (`Date.now()`) **נשמרים כמו שהם** — המערכת ממשיכה לעבוד איתם; מזהים חדשים = UUID.
- מפתחות חסרים ב-JSON (`db.plans` לא קיים) → טבלאות נוצרות ריקות.

## הרשאות

ללא שינוי מ-F0.0 (אין auth עדיין) — אבל `tenant_id` קיים בכל טבלה + טננט ברירת מחדל אחד ("Default Club") שאליו הכל מוגר; אכיפה בפועל ב-F0.2/F0.3.

## i18n/RTL

לא רלוונטי (שכבת נתונים). הודעות הדוח של ההגירה — טקסט חופשי ב-console (לא ממשק משתמש).

## מדידה

- מספר שורות בכל טבלה לפני/אחרי = זהה (חוץ מניקויים מדווחים).
- כל 17 ה-routes עונים כמו קודם (ספירת ישויות זהה בין JSON ל-Postgres).

## סקופ מודע (מה לא ב-F0.1)

- אכיפת הרשאות/tenant-isolation (F0.2/F0.3) — רק העמודה.
- מופעים יציבים/סדרות (F1.2) — הסכמה לא מקדימה אותם.
- ולידציה מלאה 400 (F0.3).
- גיבוי מתוזמן אוטומטי — סקריפט + הוראות; רישום Task Scheduler רק באישורך.
